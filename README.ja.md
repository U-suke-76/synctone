# SyncTone (シンクトーン)

[English](README.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

---

**「透明で見える、確かな数ミリ秒。」**  
歌枠・演奏配信者向け オープンソース型 OBS 音声同期アシスタントツール

---

## 特徴

* **確実なミリ秒精度検出**  
  人間の聴覚に最適でノイズに強い対数スイープ音（500Hz〜4000Hz）と、FFT相互相関・放物線補間アルゴリズムにより、0.1ms以下の超高精度で遅延を自動測定。
* **軽量・低リソース（Electron不使用）**  
  Python + PySide6 (Qt) + pyqtgraph ネイティブ構成により、メモリ消費が極めて小さく起動も一瞬です。
* **安心の可視化（Visual Feedback）**  
  ブラックボックスを排除し、基準音とマイク入力音の重なり、および相互相関ピークをグラフで直感的に確認できます。
* **OBS Studio 28+ (WebSocket v5) 完全対応**  
  検出された遅延ミリ秒を、OBS上の対象音声ソース（デスクトップ音声やマイク）へワンクリックで即時書き込み。
* **カラオケ・音ゲー・実写向け 映像レンダリング遅延連動**  
  JOYSOUNDや音ゲー画面のテロップ先行（歌詞フライング）や実写カメラのズレを防ぐため、映像ソース（ゲームキャプチャやキャプチャボード）への「レンダリング遅延（Render Delay）」フィルタも音声と同時に一括設定可能。
* **耳と目で確かめるリアルタイム同期検証（AV Sync Checker）**  
  設定後の結果をその場で直接検証可能。OBSウィンドウキャプチャ対応の「ビジュアルフラッシュ＆ビープ（映像と音声の一致確認）」と「メトロノームクリック（耳での聴感確認）」の2モードを搭載。検証画面から直接±1ms単位でのOBSリアルタイム微調整も行えます。
* **完全ローカル処理・安全設計**  
  外部通信は一切行わず、録音データもメモリ上で処理して即座に破棄されます。

---

## システム構成

* **GUI**: PySide6 (Qt 6)
* **描画**: pyqtgraph (低負荷・高フレームレート波形描画)
* **オーディオ I/O**: sounddevice (PortAudio / Windows WASAPI)
* **DSP / 解析**: NumPy / SciPy (相互相関解析・チャープ生成)
* **OBS連携**: obsws-python (WebSocket v5 プロトコル)

## 使い方

1. **OBS Studio の設定確認**  
   * OBSのメニューから `[ツール]` → `[WebSocketサーバー設定]` を開き、サーバーが有効になっていることを確認します（標準ポート: 4455）。
2. **SyncTone の起動と接続**  
   * SyncTone を起動し、ポート・パスワード（設定している場合）を入力して **「OBSに接続」** をクリックします。
3. **デバイスの選択**  
   * 「再生」に普段オケを聴いているイヤホン/スピーカーを、「録音」に測定対象のマイクを選択します。
4. **測定の実行**  
   * **イヤホンを耳から外し、マイクに近づけて密着** させます。
   * **「測定開始」** ボタンをクリックします（約1.5秒間、小さなスイープ音が鳴ります）。
5. **波形確認と手動微調整**  
   * 検出された遅延ミリ秒（ms）と波形の重なり、相関ピークを確認します。
   * 必要に応じてスライダーやスピンボックスで微調整します。
6. **OBSへ反映**  
   * 反映先ソース（例: `デスクトップ音声 (推奨: オケ遅延)`）を選択します。
   * **カラオケ画面（JOYSOUND等）や実写カメラも同時に合わせる場合**：
     * 「🎥 映像ソースにもレンダリング遅延を連動」にチェックを入れ、対象の映像ソース（ゲームキャプチャやキャプチャボード）を選択します。
   * **「測定結果をOBSに反映して返す」** をクリックします（音声オフセットと映像レンダリング遅延が自動適用されます）。
7. **同期検証（AV Sync Checker）で最終確認**  
   * **「🎧 同期検証 (AV Sync Check)」** ボタンをクリックして検証ウィンドウを開きます。
   * **視覚＆ビープモード**：OBSのソースに「ウィンドウキャプチャ」でこの画面を追加し、バーが中央(0ms)を通過した瞬間のフラッシュと音が完全一致しているかを確認します。
   * **聴感クリックモード**：メトロノーム音を再生し、OBSのモニタリング音声で音がダブらず（タ・タンと割れず）ひとつの音として聴こえるか耳で確認します。
   * 必要に応じて、検証画面内のボタンから直接「±1ms / ±5ms」のリアルタイム微調整も可能です。

## スタンドアロン実行ファイル（.exe）のビルド

Pythonがインストールされていない環境でもそのまま動作する単一のポータブル実行ファイル（`dist/SyncTone.exe`）をビルドできます：

```bash
pip install -e .[dev]
python build.py
```
