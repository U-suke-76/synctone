# SyncTone (싱크톤)

[English](README.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

---

**"투명하게 보이는 확실한 몇 밀리초."**  
노래 및 악기 연주 방송인을 위한 오픈 소스 OBS 오디오 싱크 보정 보조 도구

---

## 주요 특징

* **확실한 밀리초 단위 정밀 감지 (Sub-millisecond Precision)**  
  인간의 청각 특성에 최적화되고 주변 소음에 강한 로그 스윕 신호(500Hz ~ 4000Hz)와 FFT 상호 상관(Cross-Correlation) 및 포물선 보간(Parabolic Interpolation) 알고리즘을 결합하여, 0.1ms 이하의 초정밀 오디오 지연 시간을 자동으로 측정합니다.
* **가볍고 적은 리소스 소모 (Electron 미사용)**  
  Python + PySide6 (Qt) + pyqtgraph 기반의 네이티브 구조로 빌드되어 메모리 점유율이 극히 낮고 즉각적으로 실행됩니다.
* **직관적인 시각적 피드백 (Visual Feedback)**  
  블랙박스 방식을 배제하고 기준음 신호와 마이크 입력음의 파형 겹침, 그리고 상호 상관 피크 그래프를 직접 눈으로 확인하며 신뢰할 수 있습니다.
* **OBS Studio 28+ (WebSocket v5) 완벽 지원**  
  감지된 지연 시간(ms)을 OBS 내 대상 오디오 소스(데스크톱 오디오 또는 마이크)에 원클릭으로 즉시 반영합니다.
* **노래방·리듬게임·캠 방송을 위한 비디오 렌더링 지연 연동**  
  노래방(TJ/금영/JOYSOUND 등)이나 리듬게임의 가사/노트 선행 현상(플라잉 현상) 및 웹캠/캡처보드 싱크 어긋남을 방지하기 위해, 비디오 소스의 "렌더링 지연(Render Delay)" 필터도 오디오와 동시에 일괄 적용할 수 있습니다.
* **눈과 귀로 직접 확인하는 실시간 동기화 검증기 (AV Sync Checker)**  
  설정 결과를 즉석에서 직접 검증할 수 있습니다. OBS 윈도우 캡처를 활용한 "비주얼 플래시 & 비프(화면과 소리의 일치 확인)" 및 "메트로놈 클릭(귀를 통한 청감 확인)" 2가지 모드를 탑재하였으며, 검증 창에서 직접 ±1ms / ±5ms 단위로 OBS 실시간 미세 조정을 수행할 수 있습니다.
* **100% 로컬 처리 및 안전한 프라이버시 설계**  
  외부 네트워크 통신을 전혀 발생시키지 않으며, 녹음된 측정 데이터는 메모리상에서만 분석된 후 즉시 안전하게 파기됩니다.

## 시스템 구성

* **GUI**: PySide6 (Qt 6)
* **그래프 렌더링**: pyqtgraph (저부하, 고프레임 파형 렌더링)
* **오디오 I/O**: sounddevice (PortAudio / Windows WASAPI)
* **DSP / 신호 분석**: NumPy / SciPy (상호 상관 분석 및 처프 신호 생성)
* **OBS 연동**: obsws-python (WebSocket v5 프로토콜)

## 사용 방법

1. **OBS Studio 설정 확인**  
   * OBS 상단 메뉴에서 `[도구(Tools)]` → `[WebSocket 서버 설정(WebSocket Server Settings)]`을 열고 서버가 활성화되어 있는지 확인합니다 (기본 포트: 4455).
2. **SyncTone 실행 및 연결**  
   * SyncTone을 실행하고 포트와 비밀번호(설정한 경우)를 입력한 뒤 **"OBS에 연결"** 버튼을 클릭합니다.
3. **입출력 장치 선택**  
   * "재생"에 평소 반주를 듣는 이어폰/헤드폰/스피커를, "녹음"에 싱크를 맞출 마이크를 선택합니다.
4. **지연 시간 측정**  
   * **이어폰을 귀에서 뺀 뒤 마이크 수음부에 바짝 밀착**시킵니다.
   * **"측정 시작"** 버튼을 클릭합니다 (약 1.5초간 작은 스윕 신호음이 재생됩니다).
5. **파형 확인 및 수동 미세 조정**  
   * 계산된 지연 시간(ms), 파형 겹침 상태, 상관 피크 그래프를 확인합니다.
   * 필요에 따라 슬라이더나 스핀박스로 지연값을 수동 미세 조정합니다.
6. **OBS에 결과 반영**  
   * 지연을 적용할 오디오 소스(예: `데스크톱 오디오 (권장: 반주 지연)`)를 선택합니다.
   * **노래방 화면이나 웹캠 화면 싱크도 함께 맞추려는 경우**:
     * "🎥 비디오 소스에도 렌더링 지연 연동"에 체크하고 대상 비디오 소스(게임 캡처, 캡처보드 등)를 선택합니다.
   * **"측정 결과를 OBS에 반영"**을 클릭합니다 (오디오 지연 오프셋 및 비디오 렌더링 지연이 자동 적용됩니다).
7. **AV Sync Checker로 최종 동기화 검증**  
   * **"🎧 동기 검증 (AV Sync Check)"** 버튼을 클릭하여 검증 창을 엽니다.
   * **시각 & 비프 모드**: OBS 소스에 "윈도우 캡처"로 해당 창을 추가한 후, 인디케이터 바가 중앙(0ms)을 지나는 순간 플래시와 비프음이 정확히 일치하는지 확인합니다.
   * **청감 클릭 모드**: 메트로놈 클릭음을 재생하고 OBS 오디오 모니터링을 통해 소리가 갈라지거나 이중으로 들리지 않고 하나의 소리로 깔끔하게 들리는지 확인합니다.
   * 필요시 검증 창 내부의 버튼으로 즉시 ±1ms / ±5ms 단위 실시간 미세 조정을 진행할 수 있습니다.
